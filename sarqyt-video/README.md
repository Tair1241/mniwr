# Sarqyt — демо-ролик для инвесторов

Плоская 2D-анимация по сценарию + реальные записи экрана приложения, озвучка ElevenLabs
(голос «Pavel — Warm Conversational Narrator», модель eleven_v4), субтитры прямо в кадре.

- `index.html` — все сцены; кадр рисует `render(t)`.
- `build_timeline.py` — длительность сцен по озвучке, субтитры, дорожка голоса (`../vo/sNN.mp3`).
- `render.js` — рендер кадров через Playwright; `make_video.sh` — полная пересборка в mp4.

Записи экрана (`clips/`) и озвучка в репозиторий не кладутся: в них личные данные.
